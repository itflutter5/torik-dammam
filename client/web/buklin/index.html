Three steps to get started.

  1. Download the app

    Tap the download button on your Android phone. Wait for the APK file to finish downloading.

  2. Open the APK

    Open buklin-4.apk from your downloads. If Android asks, allow this browser or file manager to install apps from this source.

  3. Install & launch

    Tap Install, then Open to launch BUKLIN. You can turn off the installation permission afterward.

Downloading on a computer? Transfer the APK to your Android phone to install it. This file cannot be installed on iPhone or iPad.
